# Projeto Jovem VIP — Redesign

## Como abrir o projeto

1. Instale o Node.js 22.13 ou superior.
2. Abra o terminal dentro da pasta do projeto.
3. Execute `npm install`.
4. Execute `npm run dev`.
5. Abra no navegador o endereço exibido pelo terminal.

O código principal está em `app/page.tsx` e `app/globals.css`. As imagens e o
vídeo utilizados pelo site ficam em `public/assets/`.

O arquivo compactado não inclui `node_modules`, pois essa pasta é grande e é
recriada automaticamente ao executar `npm install`.
